# Developer Portfolio — Static HTML + Tailwind CSS

A restrained, developer-focused portfolio starter. It intentionally avoids the common AI-generated portfolio look: no oversized neon gradients, no decorative 3D globe, no fake metrics, and no unnecessary animation.

## Pages
- `index.html` — Home
- `about.html` — About, experience and education
- `portfolio.html` — Project grid
- `contact.html` — Contact form and resume CTA

## Structure
- `css/style.css` — Custom design system and component styling
- `js/main.js` — Mobile navigation, active navigation, reveal animation and subtle cursor
- `images/` — Replace project/profile assets here
- `resume.pdf` — Replace with your actual resume

## Personalise before publishing
1. Replace `Your Name`, initials, location, email, phone and social links.
2. Replace all placeholder copy with your actual experience.
3. Replace project titles, descriptions, technologies, thumbnails and URLs.
4. Replace `resume.pdf` with your real resume.
5. Remove any section that does not represent your actual work.

The visual system is deliberately simple: dark neutral background, one restrained blue accent, thin borders, typography, whitespace and content hierarchy. The goal is for your work to be the visual focus rather than the effects.
